🔐 Python Password Generator
📌 Project Description

This is a simple command-line Password Generator built using Python.
The program creates strong, random passwords based on user preferences such as length, numbers, and symbols.

🚀 Features

Generate secure random passwords

User chooses password length

Option to include numbers

Option to include special symbols


🛠️ Technologies Used

Python 3

Built-in modules: random, string

▶️ How to Run the Project

Install Python on your system

Download or clone this repository

Open terminal in the project folder

Run the command:

python password_generator.py

Enter your preferences and get your password
